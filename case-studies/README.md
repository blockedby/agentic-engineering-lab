# Case studies

This directory is the reading guide for portfolio case studies. Full case studies are added only after source evidence has been checked and public-safety review is complete.

| Order | Case study | Proof signal | Evidence type |
|---:|---|---|---|
| 1 | pi-codex tooling | Bounded agent tools, deterministic evidence, structured outputs | Public repo |
| 2 | Obscura browser-runtime fix | OSS debugging, runtime constraints, regression tests | Public PR |
| 3 | Hermes gateway work | Fork work around messaging/Telegram gateway behavior | Public fork, upstream attributed |
| 4 | Go OpenRouter SDK work | LLM SDK/API support and typed backend integration | Public fork, upstream attributed |
| 5 | Sanitized production workflow | Backend reliability and agent-assisted PR workflow | Sanitized private-work writeup only |
| 6 | Linux/Kubuntu automation | Practical systems debugging and recovery runbooks | Public personal runbook |

Private repositories must not be made public or added as submodules. Sanitized case studies intentionally omit private code, credentials, logs, domains, endpoints, and user data.
